# Implementation-of-Linear-Regression-Using-Gradient-Descent

## AIM:
To write a program to predict the profit of a city using the linear regression model with gradient descent.

## Equipments Required:
1. Hardware – PCs
2. Anaconda – Python 3.7 Installation / Jupyter notebook

Algorithm
1. Read the dataset from the given CSV file and select the independent variable (city attribute) and dependent variable (profit)
2. Initialize parameters such as slope, intercept, learning rate, and number of iterations.
3. Apply gradient descent to iteratively update the parameters by minimizing the mean squared error.
4. Use the trained model to predict the profit for the given input value
